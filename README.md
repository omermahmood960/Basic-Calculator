# 🧮 Basic Calculator

A simple, responsive calculator built using HTML, CSS, and JavaScript that performs basic arithmetic operations.

## 📌 Overview
This project is a front-end calculator application that allows users to perform basic mathematical operations (addition, subtraction, multiplication, division) through a clean and interactive interface.

## ✨ Features
- Perform basic arithmetic operations (+, −, ×, ÷)
- Clean, responsive button layout
- Real-time display of input and results
- Clear (C) and delete functionality
- Simple and intuitive user interface

## 🛠️ Tech Stack
- **HTML5** – structure and layout
- **CSS3** – styling and design
- **JavaScript** – calculator logic and functionality
